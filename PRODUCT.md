# Product

## Register

product

## Users

JobApps is a private local cockpit for evaluating roles, preparing application materials, and keeping useful networking context from getting lost.

## Product Purpose

JobApps turns an opportunity or person into a clear next action while keeping structured career and networking state in one inspectable database. Success means less repeated context gathering, truthful materials, and intentional follow-through.

## Brand Personality

Focused, direct, and quietly technical.

## Anti-references

Do not resemble a corporate ATS, generic CRM, gamified productivity dashboard, or decorative AI agent demo.

## Design Principles

- Put current state and the next useful action first.
- Keep agent reasoning and state changes inspectable.
- Separate user intent from automated discovery.
- Reuse familiar controls and the existing Hermes-native visual language.
- Add only the fields and operations that support a real workflow.

## Accessibility & Inclusion

Use semantic controls, keyboard-visible focus, readable contrast, responsive layouts, and reduced-motion-safe state transitions.
